# golden_cpp — reference C++ project

A small CMake project that collects the cases that are hard to index. Contract tests of every block run against it. It builds with MSVC, Clang and GCC, and needs no generated code: configuring is enough for indexing.

`expected/` holds answers written by hand from this code and the rules in `docs/carma-spec.md`. They are never generated by an adapter; otherwise the tests would check the adapter against itself. When an adapter disagrees with `expected/`, the spec decides who is right.

| Case | Where |
| --- | --- |
| render → streaming → io calls and a streaming → render call back: one cycle and one undeclared dependency | `src/render/Renderer.cpp`, `src/streaming/TextureStreamer.cpp`, `expected/model/` |
| Files directly in a subsystem folder that also has a child component (`render._self`) | `src/render/Renderer.*`, `src/render/IRenderable.h` next to `src/render/backend/` |
| Pure virtual interface and overrides | `src/render/IRenderable.h`, `src/render/backend/Mesh.*`, `src/core/Component.h` |
| Overloads, one by `std::size_t`; a function template with the same parameters as a plain overload | `src/io/IoQueue.h` (`Read`, `Enqueue`) |
| Class template, explicit specialization, implicit instantiation | `src/io/RingBuffer.h`, `apps/tool_main.cpp` |
| Macro that generates a struct; macro that adds methods to a class (like `COMPONENT` in gd-engine) | `src/io/Handles.h`; `src/core/Component.h`, used in `Mesh.h` and `TextureStreamer.h` |
| Same-named static functions in two `.cpp` files; anonymous-namespace function and variable | `Clamp` in `TextureStreamer.cpp` and `IoQueue.cpp`; `Normalize`, `g_uploaded` |
| Two `main` in two targets | `apps/app_main.cpp`, `apps/tool_main.cpp` |
| Anonymous union and struct, and a field written through them (no ID for the unnamed members clang adds); local struct and lambda in a function | `src/core/FrameStats.h`; `Renderer::DrawScene` |
| Field of a type from another subsystem (use edge from a class container) | `Renderer::m_streamer`, `TextureStreamer::m_lastHandle` |
| Function address taken without a call | `std::atexit(&OnShutdown)` in `Renderer.cpp` |
| Async hop through a task queue with a lambda (invisible to the call graph, expected) | `TextureStreamer::RequestLoad` → `IoQueue::Process` |
| Reference from a global initializer (`container: null`) | `kDefaultWidth` in `Renderer.cpp` |
| Vendored library inside the root (`_external` by glob) and the standard library (`external: true`) | `thirdparty/fakelib/`, `std::string` |
| The one deliberate platform fork | `src/io/Platform.cpp` (`WindowsDriveRoot` exists only on Windows) |

`expected/` files:

- `symbols.json` — symbols with canonical IDs, kinds, where they live and which component owns them; plus substrings that must never appear in IDs.
- `refs.json` — calls, non-call references and calls that must not exist.
- `relations.json` — inheritance and overrides.
- `model/`, `config.yaml` — the model and config the core checks run with.
- `checks.json` — issues `carma check` must report at the root level, and nothing else.
- `view_root.json` — the answer of `GET /api/v0/view?scope=root`, with the refs behind every edge spelled out.
